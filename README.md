# My IoT Dashboard Project

This project connects IoT devices to a web browser in real-time.

## How to Run:
1. Install Docker Desktop
2. Run: docker-compose up -d
3. Open: http://localhost:8081

## What I Built:
- A server that connects to IoT devices (MQTT protocol)
- A website that shows device data in real-time
- Everything runs in a Docker container

## Technologies Used:
- Node.js (JavaScript backend)
- MQTT (IoT communication)
- WebSocket (real-time updates)
- Docker (containerization)
- HTML/CSS/JavaScript (frontend)

## What It Does:
- Shows real temperature/humidity sensors
- Lets you control devices from the web
- Updates instantly without refreshing
